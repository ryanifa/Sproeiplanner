Eerste installatie

Voer een GitHub Personal Access Token (scope: gist) en het Gist ID in. Deze worden alleen op dit apparaat opgeslagen.

Maak een Gist aan met een bestand sproeiplanner.json met inhoud {}. Het Gist ID staat in de URL.

Sproei Rooster

Selecteer je naam/huisnummer en druk op de sproei button als je de sproeier hebt aangezet. Per dag hoeft slechts 1 zone te worden besproeid. Als je geen naam kunt selecteren en de sproei button is NIET zichtbaar dan heeft iemand anders al de sproeier aangezet vandaag!
